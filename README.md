# Manual Prático para Conviver com Ansiedade - Página de Vendas

Página de vendas (landing page) criada com Nuxt 3 e Tailwind CSS para o Manual Prático sobre convivência com ansiedade.

## 🚀 Tecnologias

- **Nuxt 3** - Framework Vue.js
- **Tailwind CSS** - Framework de estilização
- **Vue 3** - Framework JavaScript reativo

## 📋 Estrutura da Página

A página de vendas contém 11 seções completas:

1. **Headline Principal** - Proposta de valor clara
2. **Identificação Imediata** - Dores do público-alvo
3. **A Dor Real** - Aprofundamento do problema
4. **Quebra de Crença** - Apresentação da solução
5. **Apresentação do Produto** - O que é o manual
6. **O que Você Vai Aprender** - Benefícios e conteúdo
7. **Para Quem É** - Público-alvo
8. **Para Quem Não É** - Filtro de qualificação
9. **Oferta** - Preço e call-to-action
10. **Garantia** - Garantia de 7 dias
11. **CTA Final** - Chamada para ação final

## Setup

Instalar dependências:

```bash
npm install
```

## Servidor de Desenvolvimento

Iniciar o servidor em `http://localhost:3000`:

```bash
npm run dev
```

## Produção

Build para produção:

```bash
npm run build
npm run preview
```

## 📱 Responsividade

A página é totalmente responsiva e otimizada para:
- Mobile (smartphones)
- Tablet
- Desktop

## 🎨 Personalização

### Cores

As cores principais podem ser ajustadas no arquivo `tailwind.config.js`:
- Verde (primary): usado para CTAs e destaques positivos
- Vermelho: usado para dores e alertas
- Azul: usado para garantia e confiança

### Conteúdo

Todo o conteúdo da página está no arquivo `app/app.vue` e pode ser facilmente editado.

### Estilos

Os estilos globais estão em `assets/css/tailwind.css` com classes utilitárias customizadas:
- `.btn-primary` - Botão de ação principal
- `.section-container` - Container de seção
- `.headline` - Título principal
- `.subheadline` - Subtítulo
